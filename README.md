Designing agent architectures and workflow orchestration systems for
automation pipelines — the computer-vision and LLM-routing projects below
are the public, verifiable proof of that pattern: shipped tests, versioned
model releases, and CI, not just a demo script.

**Currently building:** end-to-end agent architectures — control loops,
provider routing, task orchestration — for personal automation and
outreach. Iterating privately, opening pieces up as they stabilize.

**Selected work**
- 🔧 [Solar-Panel-AI-Analysis](https://github.com/4keles/Solar-Panel-AI-Analysis) — multi-modal (RGB + thermal) YOLO11 defect detection for solar panels. PyQt6 live dashboard, ByteTrack tracking, versioned weights shipped to [Hugging Face Hub](https://huggingface.co/4keles/solar-panel-od) (3 releases — live download count in the badge above).
- 🔀 [llm-prompt-translator](https://github.com/4keles/llm-prompt-translator) — cost-aware local-first LLM router: complexity-based routing between Ollama (local) and Groq/Gemini, with per-token logprob entropy as the quality-fallback trigger.

**Open source**
- Merged `gTube` into [GlistEngine/GlistEngine](https://github.com/GlistEngine/GlistEngine) (383★ C++ game engine)
- Merged an Ollama provider into [05satyam/instruct_vault](https://github.com/05satyam/instruct_vault)
